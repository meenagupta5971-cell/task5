# ShopKart - Final Project (Task 5) 🛍️
By Pragya Gupta | ApexPlanet Internship

## About
A complete, fast, responsive e-commerce web app built with HTML, CSS & JavaScript.

## Features
- Home, Shop, Cart, About, Contact pages in one site
- Search, Category Filter, Price Filter & Sort
- Add to Cart, Quantity +/-, Remove, Total
- Checkout with Order Success message
- Shopping List (To-Do) with LocalStorage
- Cart saved in LocalStorage even after refresh
- Responsive for Mobile, Tablet & Desktop
- Optimized: Lazy Loading Images, Minified CSS/JS
- Cross-Browser Compatible: Chrome, Firefox, Edge, Safari

## Tech Used
HTML5, CSS3, JavaScript, LocalStorage, Flexbox & Grid

## How to Run
1. Download this repo
2. Open `index.html` with Live Server in VS Code
3. Or open Live Link from GitHub Pages
